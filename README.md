# FM Energy Workshop

> ⚠️ **Workshop Prototype** — This project is a learning prototype and is not intended for production use.

## Goal

Predict the next hour's building electricity consumption and display the forecast on an interactive dashboard.

## Planned Tools

- **Python** — data processing, model training, and prediction logic
- **Streamlit** — interactive dashboard for visualising forecasts
- **Neon Postgres** — cloud database for storing consumption data and predictions

## Overview

The project ingests historical electricity consumption data, trains a forecasting model, and serves the next-hour prediction through a Streamlit dashboard backed by a Neon Postgres database.
